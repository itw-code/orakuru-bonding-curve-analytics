# Evidence.dev Dashboard Specification: Orakuru Launchpad Intelligence

This file contains the runnable [Evidence.dev](https://evidence.dev) markdown code (`pages/index.md`) that queries the DuckDB marts generated by `orakuru_analytics`.

```markdown
---
title: Orakuru Protocol Live Analytics
queries:
  - active_curves: |
      select 
        token_address,
        curve_fill_pct,
        current_base_in_curve,
        graduation_threshold_base,
        curve_status,
        sniper_volume_penetration_pct,
        total_snipers_detected
      from dim_tokens
      order by curve_fill_pct desc;
  
  - daily_velocity: |
      select 
        trade_date,
        token_address,
        daily_volume_base,
        token_velocity_index,
        turnover_rate_pct,
        velocity_health_tier
      from fct_curve_daily_performance
      order by trade_date desc;

  - wallet_segments: |
      select 
        primary_wallet_segment,
        count(*) as total_wallets,
        round(sum(lifetime_base_invested), 2) as total_volume_base,
        round(avg(lifetime_net_pnl_base), 2) as avg_pnl_base
      from dim_wallets
      group by primary_wallet_segment
      order by total_volume_base desc;
---
```
